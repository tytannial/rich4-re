# 地图数据格式 (GND)

> 状态：**结构部分解析**，语义待结合地图渲染代码确认。
> 资源魔数 `GND\0` (0x00444E47)，仅出现在 `map.mkf`（8 个）。

## 已知布局

```
+----------------------------+ 0
| magic : u32 = 'GND\0'      |
+----------------------------+ 4
| grid_w : u16               |   72
| grid_h : u16               |   72
+----------------------------+ 8
| count : u32                |   5184 = 72*72
+----------------------------+ 12
| reserved : u32             |   0
+----------------------------+ 16
| block[512]                 |   256 x u16, 经 sub_451801 做像素格式转换
+----------------------------+ 528
| cells[count]               |   每格 1026 字节
+----------------------------+
```

- 每格大小 `1026 = (filesize - 528) / count`（8 个文件一致）
- `1026 = 2 + 1024`，疑似 `2 字节属性 + 32×32 8bit 像素`
- 实际数据呈现 `u16` 递增序列，需结合地图绘制逻辑确认（可能为高度/索引表）

## 相关资源

- `map.mkf` 中 260 个 SPR 为地图图块精灵
- 地图网格 `72×72`，若每格 32×32 像素则地图为 `2304×2304`
