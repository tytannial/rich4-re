# SAVE%d.DAT 存档格式

> 状态：**头部与玩家表已解析**，完整游戏状态待深入。
> 样本 `SAVE0.DAT` 为 90111 字节。读写见 `sub_403D74`(存档选择界面)、`sub_402AC5`(读档)。

## 头部

| 偏移 | 类型 | 字段 | 说明 |
|------|------|------|------|
| 0 | u32 | `version` | 固定 `38` (0x26)，用于校验存档有效性 |
| 4 | u32 | `datetime` | 高字为年份(`sub_457D61` 转字符串)，次/低字节用于 `%d/%d` 显示 |
| 8 | u16 | ? | |
| 10 | u16 | ? | |
| 12 | u32 | `player_count` | 玩家数（通常 4） |
| 16 | Player[4] | `players` | 每玩家 **104 字节**（`unk_48A188`, 104×4） |
| 16+416 | ... | 游戏状态 | 地图/回合/股市等（待解析） |

样本头部：`26 00 00 00 02 01 DA 07 03 00 01 00 04 00 00 00 ...`

## 玩家结构 (104 字节)

选择界面按 `104 * player_index` 寻址（与游戏中 `byte_496B79[104 * index]` 等一致）。
字段明细待逆向（含姓名 BIG5、金钱、位置、卡片等）。

## 关键观察

- 存档中含 **DGROUP 段内地址**（如 `0x4665CD`、`0x466446`），疑似**内存块直接 dump**，
  加载时需要指针重定位或按固定布局重映射
- 玩家数组按 104 字节定长，便于重建为结构体
