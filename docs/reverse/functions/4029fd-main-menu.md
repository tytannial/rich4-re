# 0x4029FD 主菜单场景 + 0x40257A 事件处理

## 基本信息

| 项 | 值 |
|----|-----|
| 地址 | `0x4029FD`（场景）/ `0x40257A`（事件处理，`0x262`） |
| 调用者 | `0x401B9C` WinMain 主循环 |
| 被调用 | `0x450441` 取资源, `0x4562A5` 布局, `0x44F9D8` 绘制面板, `0x44FABC` 绘制文本, `0x4018E7` 模态循环 |
| 重写符号 | `src/game/main_menu.cpp` `mainMenuScene` / `mainMenuEventHandler` |
| 状态 | 未开始 |

## 功能

主菜单：加载背景与 5 个按钮资源，绘制 "V3.11" 版本号，进入模态循环
处理鼠标悬停高亮与点击，返回按钮索引给 WinMain 分发。

## 逆向依据

- `0x4029FD` 反编译观察：
  - `sub_450441(dword_48A0E4, 1, 0, 0)` 从 data.mkf 取索引 1 资源（背景）
  - 循环 `i<5`：`sub_4562A5(资源+12, 资源+12+12*(2i+1), word_46CB28[2i], word_46CB2A[2i])`
    设置 5 个按钮位置（数据 `0x46CB28`）
  - `sub_44F9D8(16, 15790320, 1052688, 3, 1)`：绘制菜单面板（颜色 0xF0F0F0/0x101010）
  - `sub_44FABC(资源+12, "V3.11", 638, 470, 6)`：右下角版本号（字符串 `0x4630D0`）
  - `sub_4018E7(sub_40257A, 0)` 模态运行；返回按钮索引
- `0x40257A` 事件处理（作为模态栈顶接收消息）：
  - `WM_PAINT(15)`：`BeginPaint` → `sub_40235D`(恢复绘制) → 主表面 `BltFast` 到后台 → `sub_402250`
  - `WM_MOUSEMOVE(0x200)`：遍历 5 个按钮矩形（`word_46CB28/2A` + 资源偏移），
    命中且变化时高亮重绘（`sub_456418` 画高亮 / `sub_45643D` 恢复）
  - `WM_LBUTTONDOWN(0x201)`：按 `dword_48A184`（当前悬停索引）分发：
    - `0/3/4` → `sub_402460(0)`（恢复绘制）+ `sub_401966(索引)`（退出模态返回索引）
    - `1` → `sub_403D74(0)` 读档对话框，取消则重绘恢复；成功则退出模态返回 1
    - `2` → 退出/设置流程（`sub_454ACB`/`sub_411B53(0)`/`sub_4549CF(0)`），返回
  - `WM_USER+1(1025)`：恢复绘制 + 重绘
- 数据：按钮坐标 `word_46CB28/word_46CB2A`（5 组 u16 x,y，按索引）：
  `0:(190,380) 1:(328,380) 2:(468,378) 3:(328,450) 4:(62,380)`
  索引语义（由 `0x40257A` 点击分支与 WinMain switch 推断）：
  0 新游戏 / 1 读档 / 2 设置(模态嵌套,不退出) / 3 退出 / 4 新游戏(模式 1)
- 全局变量：`dword_48A180`(菜单资源), `dword_48A184`(悬停按钮索引,-1 无),
  `dword_48A0DC/0E0`(主/后台表面), `byte_48A178/179`(绘制暂停状态)

## 重写要点

- `[PORT]` 表面 BltFast（`vtable+28`/`+100`/`+128` 锁/解锁）→ SDL 纹理上传，
  统一走渲染层（`src/platform/renderer.cpp`）
- `[PORT]` `WM_PAINT`/`WM_MOUSEMOVE`/`WM_LBUTTONDOWN` → SDL 事件
  （`SDL_EVENT_MOUSE_MOTION`/`SDL_EVENT_MOUSE_BUTTON_DOWN`），
  事件坐标即窗口坐标（SDL 逻辑分辨率 640x480 自动换算）
- UI 绘制函数（`sub_44F9D8`/`sub_44FABC`/`sub_4562A5` 等）尚未逆向，
  先建立场景/事件结构，绘制调用以 `TODO(RE 0xXXXXXX)` 占位
- 版本号字符串 `"V3.11"` 保留（与 exe 内一致）

## 验证方式

- 5 个按钮命中区域与原始坐标一致（62/190/328/328/468, 380/380/378/450/380）
- 点击返回值与 WinMain 分支对应（0 新游戏 / 1 读档 / 3 退出 / 4 新模式）
