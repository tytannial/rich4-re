# 0x40E033 地图物件创建 / 0x417559 右键物件提示

## 基本信息

| 项 | 值 |
|----|-----|
| 地址 | `0x40E033`（createMapObject）/ `0x40AA6C`（randomCellEnt）/ `0x417559`（物件提示）/ `0x40A9D7`（拾取查询）/ `0x409B18`（拾取缓冲重建） |
| 大小 | `0x11A` / `0xC8` / `0x70E` / `0x37` / `0x420` |
| 调用者 | `0x407AD2` loadMapData（初始放置 8 个）；`0x4186BE` gameWndProc（右键提示）；`0x409B18` ← `0x40A9D7` ← `0x417559` |
| 重写符号 | `src/app/map_render.cpp` `createMapObject` / `randomCellEnt`；`src/app/object_tip.cpp` `showObjectTip` / `drawObjectTip` |
| 状态 | 已实现 |

## 功能

### 物件表（`g_cellTable` 0x496D08，46 项 x 24 字节）

| 偏移 | 字段 |
|------|------|
| +0 | 类型（`g_cellTypeInit[46]` = {1..14, 15,15, 16x10, 17x10, 18x10}） |
| +1 | 朝向（`sub_407A8C(首个出口, cellEnt)`） |
| +2..3 | cellEnt ID（u16） |
| +4 | a3（等级/参数） |
| +5 | a4（拥有者/公司） |

类型名 = `kObjectNames[类型]`（`off_47ED76`，**索引 = 类型值**，0-based）：
0=間諜（初值未用）、1=小財神、2=大財神、3=小福神、4=大福神、5=小窮神、6=大窮神、7=小衰神、8=大衰神、
9=天使、10=惡魔、11=惡犬、12=土地公、13=禮物、14=寶箱、15=死神（2 槽）、16=路障（10 槽）、
17=地雷（10 槽）、18=定時炸彈（10 槽）；图块 = data.mkf[类型+395]（407=土地公、408=禮物、410=死神、411=路障 实测）。
依据：`sub_40EAD7` `switch(类型)` case 1..15 行为（case 3 送 1 卡、case 4 送 2 卡、case 5/6 送钱、case 7/8 丢卡）。
类型 16/17/18 由玩家道具放置（`sub_446BAA`/`sub_446C88`/`sub_446D69` → `createMapObject(16/17/18)`）。

### createMapObject（0x40E033）

类型范围决定搜索槽段：`15→14..15`、`16→16..25`、`17→26..35`、`18→36..45`、其他→`type-1` 单槽；
找 `+0 == 0` 空槽写入；`a4 && type==15` → `sub_40EAD7(a4-1,0,slot+1)`（公司登记）；
cellEnt 占用位 `|= (slot+1) << 16`；返回物件 ID（slot+1）。

### 初始放置（0x407AD2）

```c
for (k = 1; k <= 11; k += 2) sub_40E033(k, sub_40AA6C(0), 0, 0);  // 1,3,5,7,9,11
sub_40E033(13, sub_40AA6C(0), 0, 0);
sub_40E033(14, sub_40AA6C(0), 0, 0);
```

`randomCellEnt`：遍历 cellEnt，条件 `(occMask & 0x80FFFF00) == 0`（无物件/玩家占用）且
`(exits[0] || exits[1])`（有路），随机选取；`near > 0` 时要求与 near 距离 > 300。

### 右键提示（0x417559）

> 触发：**左键按下**（`0x4186BE` 在 gameWndProc 的 WM_LBUTTONDOWN 分支，地图区
> `x < 440 && y > 40`）；**按住期间显示，松开左键（WM_LBUTTONUP）消失**；命中后本次点击不再处理其他逻辑。
>
> 可提示对象：**cellEnt 格子**（醫院/銀行/命運/公園/百貨公司…，名称来自 +4）、
> 地产、公司、特殊点、事件格、cellTable 物件、玩家棋子。

- 拾取：`sub_40A9D7(x, y-40)` → `sub_409B18(0)`（视口变化时重建 440x440 u16 拾取缓冲
  `dword_474938`）→ 查表得物件 ID。**命中形状**（`g_pickMask` = map.mkf[26]，5 帧）：
  cellEnt 用帧 4（51x51）、estate/corp/specPt 原版用帧 `((8-(rot+dir))&1)+2`（143x103 菱形，
  约覆盖 3x3 格）；重写记录该形状的 **SPR 像素掩码**（非零像素处才命中），
  与原版拾取缓冲语义一致——避免矩形包围盒把相邻道路格误判为地块。
  **差异**：实机点地块范围过大易误盖道路格 → 统一改用帧 4（51x51，约一个地块）。
- **所有 cellEnt 均可拾取**（占用掩码高 16 位为 0，`sub_409B18` 条件）——包括无图块的
  道路格；点击道路格显示城市/机构名
- 提示文本**逐行绘制**（原版多次 `drawText`，行距 18）：单行（cellEnt/specPt 名）
  首行 = `v9+27`；多行（estate/corp）自 `v9` 起。**行位固定**：第 1 行恒为地主
  （为空则留空行），建筑名/类型名恒在第 2 行，不随有无地主浮动
- ID 空间：1..1999 cellEnt、2000+ estate、4000+ corp、6000+ specPt、8000+ evtCell、
  低字节 0 且非上述 → cellTable 物件（槽号<<8）、玩家棋子
- 命中后：`audioPlayEffect(g_uiSoundClick)` + 提示框（`data.mkf[517]` 帧 0..3 = 4 方向 189x116）
  + 文本（`setTextFont(16, 0xF0F0F0, 0x101010, 3, 1)`）
- **位置**：框画在**点击点**（`sub_456418(帧v5, x, y+40)`，帧图形自带方向偏移）；
  v5 = `(y-40 < 框高) + 2*(x > 440-框宽)`；文本 = 点击点 + `(a2, a1+27)`，
  a2 = `±(框宽/2+9)`、a1 = `42`（v5 0/2）或 `-96`（v5 1/3）
- 文本分支：cellEnt 名称（+4）/ estate **省份/城市名（+4）**+地主+建筑名+等级 /
  corp 名称（+4）+地主+类型名+等级 / specPt 地主+名称 / evtCell 名称 /
  cellTable 类型名（`off_47ED76`）/ 玩家名
- 名称表：`off_475138`（建筑名 0..10、等级名 11..16）、`off_475150`（+6 公司名）、
  `off_475164`（+11 等级名）—— 同一字符串表的不同起始偏移

### 地标图块（特殊点/事件格）

`SpecPt.sprite`（+32）与 `EvtCell.sprite`（+26）**不是图块帧号**，而是**资源索引**（134..259）：
原版在 `0x407ECE`/`0x407F17` 按需加载 `dword_48AE4C[sprite] = map.mkf[sprite + 38]`，
绘制时取 `dword_48AE4C[sprite]` 帧 0（0x409626/0x40976E）。地图上的地标
（臺灣人壽/大宇百貨/中國信託、醫院/綠島/野柳/基隆港/石門水庫/龜山/台中港…）即来自这两张表。
重写用 `state.specTiles`（索引 = sprite 值）按需加载并绘制。

### 图块颜色（调色板[255] 替换）

绘制前原版把图块**调色板末项（索引 255）**替换为拥有者颜色（`0x40986A` 附近）：

| owner | 颜色 | 效果 |
|-------|------|------|
| `0` | `0`（黑） | **黑色轮廓**（未购买的特殊点/建筑） |
| `1..8` | `g_playerColor[owner-1]` | 玩家色 |
| `0xFF` | 不改 | 原图（evtCell 固定 0xFF） |

重写：`UiImage::setPaletteEntry/basePaletteEntry`（load 时保存原始调色板副本），
绘制循环按 `colorIdx`（-1 原图 / 0 黑 / 1..N 玩家色）设置。

### 住宅用地/商業用地：无主不绘制但可拾取（高亮形状同原版）

无主空地/公司**不绘制旗帜**（地形自带白色虚线框，原版空地即如此）；有主时绘制
旗帜并把调色板[255] 替换为玩家色。但**无主项仍登记 drawList id**（`sub_40829D` 中
estate/corp 循环：`tile=0` 仅跳过图块，`g_drawListId = 2000+n/4000+n` 照写）→
`rebuildPickBuffer 0x409B18` 对 drawList 全部 estate/corp 写拾取缓冲，因此点击空地
会弹出提示：**建筑名 / 等级 / 费用**（如「空地 / 0級 / $400」，费用 = `estate +32 + 2*level`）。
**城市/省份名称**是**道路格（cellEnt）**的提示（名称来自 cellEnt +4，如「台北市」「墾丁」）。

**高亮形状**（`0x409B18` writePickBuffer）：estate 一律 `g_pickMask` 帧
`(8-(rot+dir))&1`（0/1，71x47/71x51）、corp 一律 `((8-(rot+dir))&1)+2`（2/3，143x103），
**与 owner/level 无关**；`markPickBuffer + highlightBlink`（0x451985）据此闪烁。

> 缓冲（命运 0x44BFB1 甚至先 mark 后改 owner）。修复：`map_render.cpp` 两处无主分支
> push 后补 `hlShape=&flagTiles`、`hlFrame` 用原版帧（0/1 或 +2）；拾取矩形仍用帧 4
> （体感魔改，见下）。"无主不写缓冲"的旧表述为误读。

## 重写要点

- 不建全屏拾取缓冲：渲染时把每个绘制物件的**屏幕矩形**（含 offsetX/Y）记录到
  `state.mapHitRegions`，右键取**最后绘制**（最上层）命中项
- 玩家 ID 用 `0xF000 | 玩家号`（避免与 evtCell 8000+ 冲突）
- 提示框方向 v5 = `(y < 框高) + 2*(x > 440-框宽)`；框位置按 v5 翻转并裁剪到地图区
- 文本金额/费用（`sub_452793`）與商業用地/住宅用地价值暂未显示（后续补）

## 验证方式

新开局：地图上应出现 8 个神明/事件点图标（間諜/財神/福神/…，随机位置）；
右键点击物件/地产/玩家 → 弹出提示框显示名称（左键或再次操作清除）。
