## 功能

「託管AI」配置面板（panel.mkf[77] 帧 0 画布 435x355，blit 到 (102,62)）：列出**人类玩家**（`alive & 1`，最多 4 槽），
为每个玩家配置 AI 托管与行为参数：

| 配置项 | 控件 | 写入字段（玩家结构） |
|--------|------|----------------------|
| 托管开关 | 再次点击当前选中玩家槽 | `alive` bit2（4） |
| 使用卡片 | 勾选框 (288,107) | `byte_496B7E` bit0 |
| 使用道具 | 勾选框 (288,139) | `byte_496B7E` bit1 |
| 個性 | 乖寶寶/普通人/大老奸 (288,195/227/259) | `byte_496B7F` = 0/1/2 |
| 現金比例 | ±按钮 (298/392,328) + 滑块轨道 (310..390,327) | `byte_496B81`（0-100，步进 10） |
| 股票比例 | ±按钮 (298/392,361) + 滑块轨道 (310..390,360) | `byte_496B82`（0-100，步进 10） |
| 確定 | 按钮 (479,159)-(519,215) | 写回全部 5 字段并关闭 |
| 取消 | 按钮 (479,247)-(519,303) | 直接关闭（不写回） |

托管语义：`alive & 6`（电脑 bit1 / 托管 bit2）→ AI 自动决策（0x419976：`test g_playerAlive, 6`）；
`alive == 1` 纯人类 → 弹询问框。即托管 = 保留人类位、加 bit2。

## 逆向依据

- **初始化**（0x41E345）：`sub_456F60(byte_48BE34, 0, 24)` 清槽 → 遍历玩家，
  `if (alive & 1)` 填入槽（6 字节/槽）：`{玩家ID+1, alive, byte_496B7E, byte_496B7F, byte_496B81, byte_496B82}`；
  `v4 == g_currentPlayer` → `dword_48BE4C = 槽索引`（默认选中）；画布预渲染玩家框帧 2 @(8, 8+83i)、
  头像帧 `6+charIndex` @(80, 48+83i)；`runModal(sub_41DDA9)` 后 `sub_41906A(1)` 重绘游戏画面
- **重绘**（0x41DB91）：blit 画布 → 玩家槽循环：
  - 选中槽：高亮框（`dword_48BE50+24` = 帧 1）@(110, 70+83i) + 棋子
    `g_pieceSprites[13*id-13]+12`（帧 0）@(182, 110+83i)
  - 托管：勾选框（`dword_48BE50+48` = 帧 3）@(121, 106+83i)
  - 选项：卡片/道具勾选框 @(288,107/139)；个性勾选框 @(288, `word_4752B8[个性]`) = {195,227,259}
  - 末调 `sub_41DA61`
- **比例条**（0x41DA61）：画布 (208,265) 80x57 → (310,327)；
  10 格循环 `v0=0,10..90`：`现金比例 > v0` → `fillRect(v1, 328, 7, 22, 0xFF0000)`（v1=311+8i）、
  `股票比例 > v0` → `fillRect(v1, 361, 7, 22, 0xFF0000)`
- **控件矩形表**（`word_4752AE`，13 项 × 8B {left,top,right,bottom}，屏幕坐标）：
  ctrl 2..14 = 卡片/道具/乖寶寶/普通人/大老奸/现金-/现金+/股票-/股票+/確定/取消/现金滑块/股票滑块；
  命中用 `word_4752BE[4*i]`（= 表项 i+2）
- **交互**（0x41DDA9）：
  - WM_LBUTTONDOWN(513)：玩家槽命中 `x∈(110,226)`、`y∈(70+83i, +83)` →
    `if (i == dword_48BE4C) byte_48BE35[6*i] ^= 4`（toggle 托管）；`dword_48BE4C = i`；`byte_48BE54 = 1`；
    控件命中 → `byte_48BE54 = 控件`；ctrl 7-10/11-12 画按下效果
  - WM_MOUSEMOVE(512) 且 `byte_48BE54` 13/14：`值 = 10 * ((x - 轨道left) / 8)`（原版无 clamp）
  - WM_LBUTTONUP(514) switch：2/3 `byte_48BE36 ^= 1/2`；4/5/6 `byte_48BE37 = 0/1/2`；
    7/8 `byte_48BE38 ∓/+ 10`（0..100）；9/10 `byte_48BE39 ∓/+ 10`；11 写回 + `PostMessage(0x205)`；12 直接关闭
  - 写回（0x41E25F）：`g_playerAlive[104*id] = 槽alive`、`byte_496B7E/BF/B81/B82 = 槽值`
  - 无音效调用；无悬停音效
- **角色默认配置**：`g_charData`（0x47E80C）每角色 +14/+15/+16/+17/+18 = 卡片道具/个性/贷款%/现金%/股票%
  （如孙小美 0x03/2/60/50/30）

## 关键结构

```c
byte_48BE34[6*i]  槽数组（4 槽 x 6B）：{ID+1, alive, 卡片道具, 个性, 现金%, 股票%}
dword_48BE4C      选中槽索引（默认当前玩家所在槽）
byte_48BE54       按下控件（0=无, 1=玩家槽, 2..14=控件）
dword_48BE50      panel.mkf[77] 画布资源（帧 0 背景 / 帧 1 高亮 / 帧 2 玩家框 / 帧 3 勾选 / 帧 6+ 头像）
word_4752AE[15]   控件矩形表（ctrl 2..14，8B/项）
word_4752B8[3]    个性勾选框 y = {195, 227, 259}
```

玩家字段（内存偏移 = 存档偏移 − 19）：`+3 byte_496B7E`（bit0 卡片/bit1 道具）、`+4 byte_496B7F`（个性）、
`+5 byte_496B80`（贷款%）、`+6 byte_496B81`（现金%）、`+7 byte_496B82`（股票%）、`+8 byte_496B83`（状态恢复朝向）。

## 重写要点

- **文本**：原版在 0x41E345 中 `drawText` 预渲染到画布帧 0（20/16 号、前景 0xF0F0F0、
  背景 0x101010、阴影+粗体；確定/取消为前景 0x101010 无底色）；重写每帧按同位置/字号重绘
- **按下效果**（WM_LBUTTONDOWN 0x41DDA9）：±按钮画布帧 4/5 blit 到 (rect.left+1, rect.top+1)；
  確定/取消对 40x56 区域做 -12 通道变暗（表 0x485BE8 = `kChannelDim`）
- 槽数组/控件表按原版常量照搬（`kControls` 13 项屏幕坐标）
- 滑块拖动 `10 * ((x-311)/8)`，重写 clamp 0..100（原版字节回绕）
- 確定写回 `players[id].alive / aiCardItem / aiPersonality / aiCashPct / aiStockPct`
- **托管效果**（AI 自动行动，`alive & 6`）：`確定` 写回后，关闭面板触发 0x40DEFE
  （`alive != 1` → `playerActionFlags |= 0x80`）→ 当前回合立即由 AI 接管；其后每回合
  `beginPlayerTurn` case 5 走完整 AI 链（买股/週轉/交易/卡·道具/状态守卫/骰调/移动，
  `418c55-ai-turn-actions.md`）。headless 实测：面板 toggle→`config applied`→
  `begin player 0 turn: type=5`→自动掷骰/移动/买地
- **解除托管入口（[NEW]，非原版）**：原版工具条在 `byte_46CAFD==0`（AI/托管回合）整条锁死
  （0x418158 `if (!g_playerControl) return 0`）→ 单人局 `alive|=4` 后再无窗口打开本面板解除。
  重写放行 AI/托管回合的工具条第 3 按钮（case 2，x∈[80,120)）：`game_loop.cpp`
  `handleLeftButtonDown` 非控制期分支置 `pendingAction=102`、事件层放行对应 UP、
  `handleTopBarButton(idleOpen=true)` 跳过 0x40DEFE 收尾（不置 0x80、不抢控制，AI 回合
  状态机原样继续）；面板默认选中当前（托管）玩家槽，再点一次即 toggle 解除。
  场景 `tests/scenarios/310_host_release.txt`
- 原版关闭后 `sub_41906A(1)` 仅重绘游戏画面 → 重写侧下一帧自动重绘，无需调用
- 取消（ctrl 12/右键/ESC）不写回；无音效

## 验证方式

游戏内工具条第 3 按钮打开：切换选中玩家、再次点击切托管（勾选框出现）、调卡片/道具/个性/比例
（比例条实时变化）、確定后面板关闭；重开面板与存档读档确认字段写回；取消不改变配置。
托管自动行动：確定后当前回合即 `type=5` 自动推进；**解除**：AI/托管回合点击工具条第 3 按钮
（新增放行入口）→ 点当前托管玩家槽 toggle → 確定 → 下回合恢复 `type=1` 等待输入。
