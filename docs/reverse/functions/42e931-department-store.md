# 百貨公司（卡片店/道具店）case 15

> 入口 `landingEvent` case 15 @0x41B3B9 → `sub_42E931(objId)`（实参 = cellEnt+32 special = 6000+n，
> 非数组下标；0x419854 var_18）。objId → specPt 索引 = objId-6000。
> 人类 UI `sub_42D37F`（WndProc，SetTimer 50ms）。重写 `src/app/shop_dialog.cpp`（2026-09-25）。

## 1. 调用链

```
landingEvent(cellEntId)                                  // 0x41982D case 15
  → shopDialog(objId)                                    // sub_42E931 0x42E931
      ├─ [a3 ∈ (6000,8000) 且 specPt[a3-6000].owner == cur+1]
      │    shopOwnerGift：rand&1 ? drawGiftCard(0x445ADA) : drawFreeCard(0x441E12)
      │    → sprintf("歡迎董事長光臨\n\n送您%s！") showMessage 1500 → sub_44F230(p, 价) 价值语音
      ├─ g_playerAlive[cur] == 1（人类）
      │    shopOpenUi：加载 panel[10]/[11] → 生成商品 → runModal(sub_42D37F, 50ms)
      │    → musicPlayScene(6) / musicStackPopRestore
      └─ else（AI/托管）
           shopAiVisit：自动买卖（0x42ED8D..0x42F30C）
      末尾（a3 ∈ 6000..8000）：specPt.fund(+40) += revenue; specPt.fundPaid(+44) += revenue
```

## 4. 时序状态机（原版 `lParam` 0..4 + WM_TIMER 50ms）

| lParam | 状态 | 行为 |
|--------|------|------|
| 0 | 欢迎消息 | 消息自然完（≥2s+语音）→ PostMessage(0x40C) 滑入；**点击** → 消息跳过 + 位置直接到位 → 1 |
| 1 | 抽屉滑入 | 每 50ms：`x += vx; vx -= 3`（40→），`y -= vy; vy -= 7`（80→），clamp (5,227)；到位 → 画按钮 + 点券 → 2 |
| 2 | 提示消息 | 首次进入显示 `#0001/#0006`（`byte_48C349[page]==0` 时）；消息完 → `byte_48C349[page]=1` → 3 |
| 3 | 可交互 | 买卖/切页/离开 |
| 4 | 离开消息 | `#0004/#0010` 播完 → postModalExit(revenue) |

- 0x405（切页/进入）按 `byte_48C349[page] = settings[1]^1` 决定是否播放动画+消息；再次进入该页直接到位。
- 0x40C 动画步进也画按钮（帧 13/29 @542,13、帧 35 @556,246）；0x40D 提示；0x40E 点券框+数字。
- `dword_48C32F` 眼神动画状态、`dword_48C314` 嘴部口型倒计时、`byte_48C348` 隔帧（动画 100ms 节奏）。
- 右键（0x205）直接关闭（无告别消息）。

## 6. 商品生成（每次开 UI 一次）

- 卡片：`n = rand()%10 + 6`（6..15）；`stock = propStock` 副本按库存展开加权、抽中后副本 -1
  （**不扣真实库存**；真实库存在购买时由 `sub_4412E4` 扣）；写 `byte_48C31C[15]`。
  原版候选数组 128B 无上限（越界风险），重写截断 128。
- 道具：`misc8A[0..7]` 非 0 的槽紧凑写入 `byte_48C2F8[8]`（买一个售罄置 0）。
- 购买后 `byte_48C31C[i]=0` / `byte_48C2F8[j]=0`（售罄）。

## 7. AI 自动买卖（0x42ED8D..0x42F30C）

`g_playerAlive != 1` 时无 UI：

1. **卖卡**：卡包从前往后，`kCardAiPersona[card] - aiPersonality == 2` → 卖（卖后前移，重试同槽）。
2. **卖道具**：`kItemAiPersona[id] - aiPersonality == 2` → 全量卖出。
3. **点券 < 100**：卖最低价卡（若有）；卖多余道具（数量 >1 各留 1）；
   骑机车卖库存机车（`itemStock[15p+4]`）、骑汽车卖库存汽车（`[+5]`）。
4. **预算分配**：`budgetCard = points/2`、`budgetOther = points - budgetCard`：
   - 买卡候选 = 对每张卡按 `propStock[j]` 重复加入（价格 ≤ budgetCard 且性格差 ≠2），
     按价格降序；卡包满 15 → 停止；逐张购买（预算递减）。
   - 买机车/汽车：未骑该载具 && `itemStock[15p+4/5]==0` && `kItemPrice[4/5] < budgetOther`
     && `misc8A[4/5] != 0`。
   - 买礼物道具：顺序 `byte_4755F0[6] = {7,1,6,0,3,2}`（0-based 槽）；条件
     `itemStock[15p+slot] < 9`、性格差 ≠2、`kItemPrice[slot] <= budgetOther`、`misc8A[slot] != 0`。

**性格字段**：`kCardAiPersona[31]` / `kItemAiPersona[14]`（`g_cardInfo+7` / `g_itemNames+7`）。
值域 0..2 且 `c - persona == 2` 仅 `persona=0, c=2` 成立 → 实际只有「乖寶寶」会主动卖出/回避 c=2 的卡与道具（原版如此，照抄）。

**载具回收库存 `byte_497324/325` 实为 `misc8A[4]/[5]`**（礼物池的机车/汽车槽）：
`damagePlayer` 0x40CD3B/43（载具损毁 ++）、命运事件车祸 0x44CB49、`newGameInit` 初始载具 --
（`misc8A[3+travel]`）；`kMisc8Init` 初值 10。

## 8. 重写要点与差异

- **重写位置**：`src/app/shop_dialog.cpp`（`ShopState` + `renderShop` + `shopModalHandler(50ms)` +
  `shopTick`/`shopAdvanceClerk`/`shopAdvanceMouth` + `shopBuyCard/Item`、`shopSellCard/Item` +
  `shopAiVisit` + `shopOwnerGift`）；
  `landingEvent` case 15 接入；`playValueLine`/`playLine`（item_effects.cpp）；`drawCardBagAt`/
  `drawItemBagAt`（card/item_bag_dialog.cpp，带坐标公共绘制）。
- **全量重绘**：原版在资源表面局部绘制 + InvalidateRect；重写每 tick（50ms）全量重绘。
  动画期间每帧补画 `FloatMessage::redraw`（新增接口，跳过 `#NNNN` 前缀避免重播语音）。
- **点击跳过**：欢迎/滑入阶段 → 消息跳过 + 位置直接到位；提示/离开 → 立即推进阶段。
- **购买置灰**（2026-09-25 实机反馈）：原版把已购行的灰色（0xA0A0A0）名字/价格**画入资源表面**
  保留，仅清 `byte_48C31C/2F8` → 视觉为置灰而非消失；重写用 `cardsSold[]`/`itemsSold[]` 标志，
  渲染分白/灰两趟绘制，点击忽略已售罄槽。
- **到位时序**（2026-09-25 实机反馈）：切页/离开按钮与点券框在抽屉到位（0x40C 结束画帧 13/29+35、
  0x40E 画点券 37）后才出现；重写 `arrived`（非 Welcome/Slide）条件控制，消息/滑入期间不显示。
- **眼睛/嘴部分离**（2026-09-25 实机反馈三次修正）：**眼睛**（帧 4..8/20..24）常驻随机眨眼、
  触发采样降频 1/32（原版 1/16）；**嘴部口型**（帧 9/10/11、25/26/27）按原版条件
  `floatMsgActive() || dword_48C314`——**消息显示期间持续循环**（1/4 每 100ms 张嘴 + 倒计时
  1..7 后闭嘴），无消息且倒计时归零后静止；tick 内顺序须 `msg.advance` 在前、口型在后
  （同原版 WM_TIMER）。
- **帧锚点**：blit 落点直接抄原版实参（`clipBlit` 内部减 offset）；抽屉/柜台/按钮用
  `blitElementOpaque`（原版 blitElementFullscreen 语义）或 `blitElement`（sub_456418 色键）。
  **例外**：店员眼睛帧 A 组原版实参为 `Rect.right/bottom` 笔误（见 §2），重写按 `Rect` 左上角。
- **差异**：① 原版卡片列表行索引无上界（i=16 越界读入道具表），重写防越界；
  ② 中奖 `drawGiftCard` 池空时原版 0 索引误指向烏龜卡名字（g_itemNames[0] 与 g_cardInfo[30] 重叠），
  重写跳过赠礼并保留日志；③ 原版 AI 候选数组 128B 溢出风险，重写截断 128；
  ④ 卖出返点的 x87 `fistp` 为**就近舍入**（13.5→14、22.5→22），重写用 `std::nearbyint`；
  ⑤ 商品列表文字原版按需局部重画，重写随全量重绘（视觉等价）。
- **未使用**：道具店消息 `#0009 這個道具會員才能兌換！`（`off_4755C0[11]`）原版函数内无引用，
  重写保留在表中备用。
