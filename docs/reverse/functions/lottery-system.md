**摇号算法**（状态 3）：
```
统计每玩家注数 counts[1..8] 与已售号 sold[]
若所有 counts ≤ 10 或 sold 空 → num = rand()%36+1（可能无人中奖）
否则 num = sold[rand()%soldCount]（保证有人中奖）
```
**结算**（状态 10）：中奖 → `addMoney(winner, g_publicFund, 现金)` + 池清零 + 号码表清空；
无人中奖 → 池与号码表**都保留**（累积到下月）。音效：摇奖 57、中奖 58。

## 7. 重写差异

1. **即时绘制 vs 表面保留**：原版各状态只画增量、靠 backbuffer 保留；重写每 tick 按状态全量重绘
   （`drawDraw` 分支按状态复原最终画面，含"FLC 末帧保留/被重铺擦除""红圈/口型覆盖帧保留"等语义）。
2. 投注界面金额原版仅首帧画一次（`byte_48C371`）；重写每 tick 重画（等价且避免 FLC 覆盖闪烁）。
3. 开奖点击跳过消息（左键/Esc/Enter）为现代化便利（原版无鼠标交互）；等待 500ms 用 10 tick 延时等价。
4. 摇号计数保护：原版栈布局只查部分玩家计数（IDA 反编译变量重叠）；重写查全部 8 位玩家。
5. 命中区右/下边界越界格（原版 quirk 读相邻内存）重写做 0..35 保护。
6. 人物眨眼/嘴部动画全量重绘等价：眨眼 4 帧一次性、type 3/4 锁存位比较、覆盖帧（眼/口型）
   持久补画 + 人物重绘状态转换时清除；type 3/4 "与锁存位相同不重绘"时保留旧覆盖。
   state 6 时刻的「累積獎金」文字原版右端被重铺截断约 20px，重写画完整（微小差异）。
7. 存档：`saveGameToSlot` 已写 `publicFund` + `lotteryNumbers`；`loadGameFromSlot` 完整恢复待 P5。
   时光机快照 `TurnSnapshot` 已含两者（原版 0x44808A 引用）。
8. **闪烁花屏修复（2026-09-29）**：投注/开奖界面每 tick 全量重绘 + 软件光标
   `Cursor::update` 旧实现"先 uncompose 写回上一轮保存的 32×32 背景"——移动鼠标时
   旧块与新背景（变暗格/装饰/FLC 变化）不符 → 一帧脏块（实机"轻微闪烁花屏"）。
   update 改为只推进动画与位置跟踪，compose 由 `Application::renderFrame` 每帧从最新
   干净背景重抓（present 后 uncompose 恢复）。开奖摇奖（state 3）/中奖 FLC（state 5）
   动画段 `Cursor::setHidden` 隐藏光标（现代化增强，原版全程自绘）；见 ui-controls §39。
