# 股市系统（股票行情 / 控股 / 交易市场）

> 覆盖：股票行情 `stockTick`、认购/买卖、控股与经营権 `updateSpecPtControl`、数字输入框、
> 行情界面（工具条按钮 10）、交易市场（工具条按钮 9，玩家间挂单）。
> 帮助依据 `[HELP 20]`（公司企業）、`[HELP 3]`（房地產統計：土地/連鎖店/設施）。
> 关联：`pricing-formulas.md` §5（specPt 收费公式）、`41982d-estate-rent.md` §4.0.1。

## 3. 关键公式与常量

- **价格档位**（`sub_428EC5`）：`≥150 → 1.0` / `≥50 → 0.5` / `≥15 → 0.1` / `≥5 → 0.05` / else `0.01`；价格 clamp `[1, 9999]`
- **动量**：clamp `±10`；远离基准（上市 = `specPt.feeBase/10000`，非上市 = 基准价）→ `×0.5`（顺向）或 `×2`（逆向）
- **涨跌扰动**：个股 `(rand()-0x4000)/1171`，全局 `(rand()-0x4000)/4097`
- **AI 买股**：保留 `g_startMoneyVal × 0.3 × M`，余额全买（`sub_41D839`）
- **认购上限**：`min(cash / 每股价格, sharesLeft, 1000)`（帮助写 2000 张，以 IDA 为准）
- **控股排序**：`shareholders[4]` 降序；`>=` 时停（平手归先拥有者）
- **specPt 一级市场可售**：`10000 - 发行股数`（`loadMapData` 初始化；MAPDAT 原始值为 0）
- **行情界面买入上限**：`min(银行 / 现价, 银行可售股数)`
- **停牌/新闻**：`byte_496986`（停牌 → 动量 0）、`byte_496987`（bit4 → +10 否则 -10）

## 4. 帮助规则（[HELP 20] 公司企業）

- 停留他人公司行號 → 按该公司消费方式缴费，**充作累积盈余**（`specPt.fund`）
- 付费后可**认购股份**（原版每次上限 2000 张）
- **持股比任何人多 → 获得经营権（董事长），享有免付费特权**（`landingEvent` 用 owner 判断）
- 别人持股超过 → 电脑自动移交经营権；**平手归先拥有者**
- **每月 15 号**按持股比例发放盈余（分红）；公司亏损由股东分担
- 11 种行业：航空（转盘出国天数）/ 電腦（使用费）/ 保險（转盘投保）/ 汽車·石油（加油站保养/加油费）/ 房地產 / 幫派（idx12）等
